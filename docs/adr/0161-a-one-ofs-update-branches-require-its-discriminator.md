# A one-of's update branches require its discriminator

A discriminated `OneOf` attribute's update schema left the discriminator out of each branch's `required`, because a partial `PATCH` without it falls back to the stored variant, while the same union as a list element required it and OpenAPI expects the discriminator in every value it selects a branch for. Every write branch now requires it. Leaving it optional did not describe the fallback anyway: the right branch depends on the stored value, which a static schema cannot see, and a partial value naming members two variants share matched more than one closed branch and failed the `oneOf`. The server keeps the fallback for a client that leaves the discriminator out, and a client that restates it still sends only the members it changes, which merge onto the stored variant.
