# A list of a one-of takes the keys any variant declares

A list of blocks that are text, images or dividers rendered every member of every item, because `*` only reached a list of a single `Obj`. Each variant now opts in on its own through `OneOfBuilder::selectableKeys($variant, ...)`, since a variant's children are declared on the union's builder and have no builder of their own to call it on; a key after `*` is accepted when one variant accepts it, a path keeps going inside the variants that accept it, and the OpenAPI `anyOf` gains the union of the variants' paths, so the generator contract doesn't move. Each item renders the selected keys its own variant accepts and nothing more, the same as an `Obj` item missing a selected member, so an image whose variant doesn't let a request select `title` renders without it, rather than whole, which would hand a client every member of the variants that never opted in. The discriminator always renders, because a client reading a narrowed item needs to know which variant the rest belongs to, and an undiscriminated item accepting none of the keys renders as `{}`. A `OneOf` attribute outside a list still renders only whole.
