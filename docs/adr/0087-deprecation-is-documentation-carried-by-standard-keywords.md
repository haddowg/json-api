# Deprecation is documentation, carried by the standard keywords

A type, an operation, an action, a field, a relation, a filter or a sort can be marked deprecated, and the projector says so with OAS 3.1's own `deprecated` on operations and parameters and JSON Schema's `deprecated` annotation on properties, so every existing tool reads it and the server's behaviour never changes. A type's and an action's deprecation arrive on new opt-in metadata interfaces, keeping hand-written metadata compiling, with single operations named in the grammar operation examples and scopes use. A deprecated sort key can't be marked inside an enum, so it is listed under the `sort` schema's `x-deprecated-sorts`, while a deprecated sort family flags its own `x-sort-families` entry rather than sharing that list, where a prefix could be read as an exact key. A document carrying any of these markers declares its own scoped contract tier, so a generator that predates them is warned it may drop them while every other document keeps its stamp.
