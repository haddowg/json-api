# A field builder carries the type its write hooks receive

The adapters check each written value's JSON type before hydrating it, so a hook typed `string` on a `Str` field is safe, yet `fillUsing()` and `deserializeUsing()` declared the value `mixed` and every author had to narrow it again. Each field builder now takes a covariant `TValue`, set by its `make()` to the type the check guarantees and widened through `@phpstan-self-out` by the calls that change what a write may carry: `nullable()`, the `onCreate()`, `onUpdate()` and `when()` scopes PHPStan can't see into, `enum()` and `in()` over enum cases, and `deserializeUsing()`, which makes it `mixed`. An `Integer` casts a validated whole number such as `5.0` to `int` before hydration, at any depth, so it takes `int`. A `when()` condition's value stays `mixed` because validators ask it before the type check, and relations keep `mixed`. A builder carries its type from left to right, so a widening call written after the hook does not reach it. `tests/StaticAnalysis/HookValueTypes.php` holds each case, its refusals proved by ignores that fail the run once unmatched.
