# A document declares its top-level meta per operation

A client generated from the OpenAPI document read every top-level `meta` as an open object, so an action reporting how many items it marked, or a collection reporting its unread count, was untyped. A type now declares its members per operation through `documentMeta()`, and an action on its `ActionResource`, `ActionCreated` or `MetaResult`, with the field builders an attribute takes, as an error descriptor declares its `meta`. Each declaring operation answers with a document component of its own narrowing the shared one, so a type declaring nothing keeps its documents unchanged. Operation-scoping fluents on the field builders were rejected because they would leak onto attributes.
