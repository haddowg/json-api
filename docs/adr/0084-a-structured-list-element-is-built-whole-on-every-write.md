# A structured list element is built whole on every write

An `ArrayList` whose elements are an `Obj` or `OneOf` reads and writes each element through that shape's children, but unlike an `Obj` attribute it never merges a write onto the stored value: a list has no identity to pair an incoming element with a stored one, and merging by index would quietly carry one element's keys into another after an insert or a reorder. So every write replaces the whole list and builds each element from nothing, which is also why the projected update schema requires inside an element what a create does, and why a child the operation may not write is dropped rather than kept. Hooks, `each()` and `sorted()` stay on the list or the children, never on the element, so the element remains a pure shape that adapters can validate per index.
