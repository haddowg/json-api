# A nested fieldset reaches every item of a list through a wildcard

A repeating group, such as the lines of an order, still rendered every member of every item, so a nested fieldset member now takes `*` after a list's name, as `lines.*.sku`, and renders the list with its length and order kept and each item trimmed to the nested fieldset inside it. The list declares nothing: `*` is accepted only on an `ArrayList` whose element is an `Obj` declaring `nestedFieldset()`, which then governs the keys after it, so the opt-in stays per level as ADR 0143 set it, and `*` on a scalar, an object, a list of scalars or a list whose element declares no keys is the unrecognized fieldset member. There is no index segment, since an item's position isn't a stable address, and `lines.*` alone selects the same as `lines`. `NestedFieldset` holds a list's nested fieldset under the one key `*`, read through `items()`, so a list's `extractUsing()` hook sees what every item needs, and the OpenAPI `anyOf` gains one pattern per path through a list in the same shape as the others, so the generator contract doesn't move.
