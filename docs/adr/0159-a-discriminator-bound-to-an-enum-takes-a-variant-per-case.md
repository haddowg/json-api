# A discriminator bound to an enum takes a variant per case

A union whose variants are the cases of an enum repeated each case's value as a string, and nothing caught a case left without a variant. `discriminator($property, $enum)` now binds the discriminator to a string-backed enum through a template and `@phpstan-self-out`, so `variant()` takes only that enum's cases and `variants()` takes a closure over the case, which core calls once per case so that a `match` missing a case fails both PHPStan's exhaustiveness check and the build. Building also fails when a case has no variant, and no variant may declare a member named like the discriminator. A `fillUsing()` hook and the hydrated value hold the case, the wire and a hook's selection keep its backing value, and the OpenAPI branch keeps its `const` beside a reference to the enum's component. An int-backed enum is refused, since a discriminator's values are strings in OpenAPI.
